# ⚠️ Experimental Research Disclaimer

This project is an **experimental prototype and research exploration**. 

It is **NOT** a clinically validated medical diagnostic device. The hardware and software within this repository are intended solely as a proof-of-concept to investigate the feasibility of using thermal asymmetry as an early screening tool using embedded machine learning. 

Do not use this system to diagnose, treat, cure, or prevent any disease, including brain strokes. Always seek the advice of a qualified healthcare provider with any questions you may have regarding a medical condition.
