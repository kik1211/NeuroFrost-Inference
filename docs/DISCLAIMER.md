# ⚠️ Experimental Research Disclaimer

This project is an **experimental prototype and research exploration**.

It is **NOT** a clinically validated medical diagnostic device. The hardware and software within this repository are intended solely as a proof-of-concept to investigate the feasibility of using temporal infrared thermometry patterns as an input to an embedded machine learning classifier.

**This system does not diagnose, treat, cure, or prevent any disease, including stroke.** The classification labels (`normal` and `stroke`) are labels assigned during model training and do not constitute medical diagnoses.

Always seek the advice of a qualified healthcare provider with any questions regarding a medical condition.
